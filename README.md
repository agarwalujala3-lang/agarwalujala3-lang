## Featured Projects

### ReceiptPulse

Serverless receipt intelligence platform built on AWS.

- Upload receipts through a live web console
- Extract vendor, date, total, and line items with Textract
- Route low-confidence or duplicate receipts for review
- Store analytics-ready data in DynamoDB
- Visualize spend, review pressure, receipt history, and exports in a polished dashboard

Live: [ReceiptPulse Console](https://d2ijsg7huf2h2p.cloudfront.net/?v=20260321h)  
Repo: [ReceiptPulse](https://github.com/agarwalujala3-lang/ReceiptPulse)

### LumenStack AI

AI-powered codebase architecture analyzer built with Node.js, Express, and JavaScript.

- Analyze GitHub repositories and uploaded ZIPs
- Detect modules, manifests, dependencies, and relationships
- Generate Mermaid architecture diagrams
- Support compare mode, exports, and codebase chat
- Present everything in a polished AI-style interface

Live: [LumenStack AI](https://lumenstack-ai.onrender.com)  
Repo: [LumenStack-AI](https://github.com/agarwalujala3-lang/LumenStack-AI)
